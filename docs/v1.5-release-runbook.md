## 1. 门禁（必须全绿才能出包，AGENTS.md §4）

```powershell
flutter analyze --no-pub        # 必须 0 issue
flutter test --no-pub -j 1      # 必须全绿（skipped 是允许的，但每一条都要有理由注释）
```

**`-j 1` 不是可选项**：并发跑会在本机出现 framework 级停摆（本仓库记录在案）。

## 2. Android：**一律分包**（AGENTS.md §1）

```powershell
flutter build apk --release --split-per-abi
```

**绝不要**用 `flutter build apk --release`（那会产出 universal 包）。原因（v1.3.2 实测）：
universal 80.5 MB，其中 `lib/` 76.1 MB 为三套 ABI；一台 arm64 真机为它永远用不到的两套架构多下 ~50 MB。

**打完必须检查并删掉残留的 universal 包**（上一次构建留下的）：
```powershell
Remove-Item build\app\outputs\flutter-apk\app-release.apk -ErrorAction SilentlyContinue
```

产物（三个都要报给用户，至少报 arm64）：
`app-arm64-v8a-release.apk` / `app-armeabi-v7a-release.apk` / `app-x86_64-release.apk`

**⚠️ versionCode 会被 ABI 加权**（v1.3.2/build 10 实测 → 1010 / 2010 / 4010）⇒ 装过分包之后
**universal 包会被判为降级而装不上**，必须先卸载。这是"订了分包就别回头打 universal"的又一理由。

## 3. Windows：exe + 安装器

```powershell
flutter build windows --release
```

**在本机编译安装器**（路径是用户级的，别只查 `Program Files`）：
```powershell
& "C:\Users\PC\AppData\Local\Programs\Inno Setup 6\ISCC.exe" installer\mconnect.iss
```
安装器现在有 `[Code]` 段检测 **VC++ 2015–2022 x64 Redistributable**（缺失时给可操作提示而不是
让用户面对一个闪退的 exe），并用 `#if FileExists(...)` 包住 `ChineseSimplified.isl`
—— **Inno Setup 不自带中文翻译**，硬引用会让没装该 `.isl` 的机器编译失败。
⇒ **如实告知用户：中文向导只在装了该 `.isl` 时生效。**

## 4. 一键脚本

`scripts/release.ps1` 按顺序做：版本一致性检查 → `analyze` → 全量测试 → 分包 APK →
**删除残留 universal 包** → Windows 构建 → ISCC → 打印产物与体积。
开关：`-SkipTests` / `-SkipWindows` / `-SkipInstaller`（**注意**：跳过的步骤必须在交付说明里写明，
不要把"脚本跑过了"当成"每一步都验过了"）。

## 5. 交付时必须说清的四件事

1. **三个 APK 的路径与体积**，以及"发给别人用 arm64"。
2. **Windows 安装器的编译状态**：本机没跑就是"**未验证**"，不要写"已验证"。
3. **【需真机】清单**（逐条标未验证）：换源真机可播与来源角标、预解析的实际请求量、
   通知栏小图标（`drawable/ic_stat_music`）、Android 小组件渲染与点击（含冷启动）、
   Android Auto 全链路（DHU/真车）、系统分享面板（歌词分享图）、悬浮窗视觉、KRC `[language:]`、
   Maloja 端点、`user.getInfo` 探针、release 下的 R8 收缩。
4. **release 签名现状**：当前 `signingConfig` 指向 **debug keystore**，这是用户 2026-10-04 的
   明确选择。⇒ 已安装用户的数据（drift 库 / Hive 设置 / 统计 / 歌单 / 下载目录配置）在换签名时
   **会丢**，必须先与用户确认；且 `C:\Users\PC\.android\debug.keystore` **一旦丢失或重生成，
   老用户永远无法升级**（提醒备份）。

## 6. 回滚

- 出包失败不需要动 git：`flutter build` 是纯输出操作。
- **只有动过 git 的东西**才需要回滚。任何 revert 之后**必须**：① `git diff` 为空或 SHA256 逐字节
  相同；② **重跑门禁**。本仓库把"回滚后没复跑"记为已发生过的事故来源。
