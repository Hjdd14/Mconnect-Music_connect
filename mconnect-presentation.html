PROJECT OVERVIEW

为什么选择 Mconnect？

一站式解决多平台音乐管理的痛点，聚合三大平台资源，提供统一的音乐体验

🔍

统一搜索

一次搜索，同时检索网易云、QQ音乐、酷狗三大平台，快速找到想听的歌曲

🎵

聚合播放

无需切换应用，统一播放器支持所有平台，自动选择最佳音源

📋

歌单同步

跨平台歌单导入导出，本地歌单管理，支持Mconnect链接分享

💾

离线缓存

智能缓存中心，自动清理策略，离线也能享受音乐

CORE FEATURES

核心功能

覆盖音乐播放的完整生命周期，从发现到收藏，从播放到管理

  • 三平台搜索/播放/歌词/登录/推荐/排行/歌单/收藏/下载
  • 全屏/迷你播放器/播放队列/音质切换/歌词同步/双语歌词
  • QRC/KRC逐字歌词支持
  • 我喜欢/听歌历史/歌单导入(分页完整)/下载管理/本地音乐
  • 平台歌单: 创建/收藏/搜索/详情/编辑
🔍

智能搜索

同时检索三大平台，自动去重排序，支持歌手、专辑、歌单多维度搜索

▶️

无缝播放

统一播放队列，自动音质选择，播放记忆与断点恢复，手势操作优化

📥

批量下载

支持多平台下载，进度实时显示，下载队列管理，自动重试机制

TECHNICAL ARCHITECTURE

技术架构

采用现代化技术栈，确保高性能、可扩展性和良好的开发体验

Flutter 3.38
跨平台UI框架，一套代码支持Android、iOS、Windows、macOS、Linux
Dart 3.10
高效编程语言，AOT编译，优秀的类型系统和空安全
Riverpod
现代状态管理，编译时安全，依赖注入，自动销毁
Drift (SQLite)
响应式数据库，类型安全查询，WAL模式，批量操作优化

SUPPORTED PLATFORMS

三大平台聚合

深度整合网易云音乐、QQ音乐、酷狗音乐，保留各平台特色功能

UNIQUE FEATURES

特色功能

超越基础播放，提供沉浸式音乐体验和智能化管理

  • Android SYSTEM_ALERT_WINDOW 悬浮歌词
  • Windows Win32 原生置顶透明窗口
  • Android just_audio equalizer 均衡器
  • Hive 本地统计/总播放次数/累计时长
  • 智能歌单规则编辑器
  • 睡眠定时器/淡入淡出
🎤

悬浮歌词

FLOATING LYRICS

Android透明覆盖层，Windows Win32原生置顶窗口，实时同步歌词显示，支持双语对照

🎛️

音频均衡器

EQUALIZER

Android原生均衡器支持，多频段调节，预设音效切换，个性化音频体验

📊

智能歌单

SMART PLAYLISTS

规则编辑器创建虚拟歌单，基于播放历史、喜好、标签自动聚合歌曲

📈

听歌统计

LISTENING STATS

本地Hive统计，总播放次数、累计时长、最爱歌曲排行，数据可视化展示
